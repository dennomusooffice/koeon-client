# Contributing — pre-publication draft

`EXTERNAL_CORE_PRS = CLOSED_INITIAL`

This local staging tree is not accepting external core-code pull requests. Before publication, Human owners must define governance, a Code of Conduct, DCO/CLA decision, review authority, security intake and trademark rules.

Future documentation-only contribution guidance may be opened by an explicit Human decision. Do not submit credentials, invite codes, Production endpoints, recordings, user/channel/device identifiers, Event assets, signing material or private operational details.

Commercial OEM/dual-license architecture is approved for design only. No contributor agreement or license grant beyond the unmodified license candidate is created by this draft.
