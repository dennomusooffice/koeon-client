# 新規端末: 最大4時間の受入れ試験

SIM5を前日に準備・ビルドしておく。端末1台につき以下の240分を上限にする。USB信頼/PIN/利用登録/アカウント同意が未準備ならその時間も計上し、残りケースを短縮して合格扱いにしない。予備20分を使い切ったら未実施を明記する。

| 経過 | 分 | 試験 |
| --- | ---: | --- |
| 0–20 | 20 | 型番/OS/build/署名/ハッシュ、権限、登録、USB接続、設定原本、journal開始/回収の基準 |
| 20–45 | 25 | READY/POWER、全5相手への送受信、音量/明瞭さ/語頭語尾、5回連続、release後の次PTT |
| 45–70 | 25 | 内蔵/有線/実Bluetooth（あるもの）、接続中/切断後の送受信、AUTO/OFF/MANUAL、弱音/過大音/無音 |
| 70–100 | 30 | 12/24/48kbps、実測した128kbps上下、低品質網で制御待ちと音声を別測定 |
| 100–135 | 35 | 1/5/15分の画面OFF/背景初回受信、各初回だけ送信し失敗直後ログ回収 |
| 135–160 | 25 | 通信断/復帰、Wi-Fi⇄LTE（許可範囲のみ）、アプリ再起動、登録維持、再参加 |
| 160–185 | 25 | 短押し/連打/同時押し、長送信上限、着信・focus割込み・明示音声再接続 |
| 185–205 | 20 | バッテリー/省電力/熱、背景service/APNs差、車載機材があれば限定接続確認 |
| 205–220 | 15 | 複数端末journal＋サーバーログ照合、時刻ずれ/欠落/誤判定の確認 |
| 220–240 | 20 | 予備、設定復元、証拠保存、Issue/端末互換表更新 |

合格ゲート: 登録消失/クラッシュ/送信保持/別世代の再生/復旧不能がない、有限PTT後にREADY、必要な各経路で双方向の可聴確認、全必須ケースに証拠、復元完了。事故的な無音は再現しなくても記録し、未解決なら条件付きまたは不合格にする。

最終判定は `ACCEPTED`（必須全件）、`CONDITIONAL`（未搭載ヘッドセット/車載等の明示的未実施）、`REJECTED`（重大不具合）、`ENV_BLOCKED`（測定/接続不能）。機種互換表にはOS更新後の再確認日も記載する。シミュレーターのハードウェア名を実機の同等品として代用しない。
