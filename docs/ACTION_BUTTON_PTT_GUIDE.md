# iPhoneのアクションボタンで送信する

更新: 2026-11-11。**1.0（2026111107）を既存の内部・外部テスターへTestFlight配信済みです。** TestFlightでKOEONをこの版へ更新してから利用してください。既存のTestFlight版すべてで使用できるという案内ではありません。

## 最初の設定

1. アクションボタンを搭載したiPhoneに、対応版のKOEONをインストールします。
2. KOEONで送信できるユーザー・チャンネルを選び、POWERをONにします。接続が完了し、READYになるまで待ちます。
3. KOEONのSettingsで「アクションボタンPTT（試作）」を確認します。2026111107以降は未設定時にONです。以前にOFFへ設定した場合は、その設定が保持されるためONへ変更してください。
4. iPhoneの「設定」→「アクションボタン」で「ショートカット」を選びます。
5. ショートカットの選択画面でKOEONを探し、「送信を切り替える」を選びます。

KOEONの操作が選択肢に出ない場合は、対応版を確認し、KOEONを一度開いてから設定画面へ戻ってください。待機処理を入れた試験用ショートカットを作る必要はありません。

## 使い方

アクションボタンを長押しすると送信開始、もう一度長押しすると停止します。押している間だけ送信する操作とは異なります。開始音を確認してから話してください。ボタン操作直後の振動は送信開始の合図ではありません。接続復帰が必要な場合、開始音まで数秒かかることがあります（開発版の待機後試験では約4.7秒）。連続送信には60秒の上限がありますが、話し終わったらボタンで停止してください。

アプリを背景にした状態や画面ロック中の利用を目指しています。背景待機後の初回復帰を限定条件で確認しましたが、すべての端末・通信状況での成功を保証していません。POWER OFF、未参加、送信権限なし、他の人の送信中、通話などによる音声の割込みでは開始できないことがあります。アプリを強制終了した状態からの自動参加・送信は案内対象外です。

## エラーになった場合

KOEONを開いてPOWER、接続状態、READYを確認してください。接続復帰中は完了を待ってから再操作します。繰り返し失敗する場合は、発生時刻、表示されたエラー文、前面／背景／ロックの別、アプリのビルド番号を管理者へ伝えてください。パスコードや認証情報を送る必要はありません。

開始音が鳴っても相手に声が届かない場合は、相手側の接続状態も確認します。開始音と音声到達は別の確認です。

## 無効にする

KOEONの「アクションボタンPTT（試作）」をOFFにします。iPhoneのアクションボタンを別用途に戻す場合は、iPhoneの「設定」→「アクションボタン」で希望の操作を選び直します。

## 配信・検証の状況

- 設定名は現在の開発版の表示です。正式な表示変更時にはこの手順も更新します。
- 開発版2026111102では接続直後と、停止から5分14秒待機後の最初の操作で開始・停止を確認しました。以前の2026111101では待機後のエラーが再発したため、1102へ修正しました。配信版の案内は冒頭の配信状況に従ってください。
- Androidの背景音量ボタンは別の試作です。このiPhone用手順はAndroidには適用しません。
