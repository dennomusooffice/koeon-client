## RXレベル追加要求（実装前）

所有者が音量レベル表示の実装を追加承認。SDKの既存受信PCM観測箇所からRMS dBFSを計算し、RAM内の数値だけを最大10HzでUIへ渡す。PCMを複製/キュー/保存/送信せず、再生や音量制御を変更しない。TX INは既存の入力RMS、RXはデコード後/端末出力音量前のRMSとして区別する。無音は-96dBFS、未取得/未対応形式/300ms以上古い値/切断は「—」。Androidの複数トラックは最新値の最大（混合音圧とは異なる）、iOSはSDK混合受信PCM。安全なバッファ境界、非有限値拒否、サンプル数上限、退出/旧トラックの無効化を検証。合成PCMで数値/無音/形式/失効回帰を追加し、指定実機で有限PTT送受信時のメーター更新と停止を確認する。聴取品質の証明とはしない。サーバー変更は不要で#43に計測契約を追記する。

所有者の外出中2時間の自律開発・試験指示により、指定2台の新しい許可枠を2026-11-11 18:02:20〜20:02:20 JSTとする。実機操作ガードもこの期限に更新。

TX表示は既存の発話全体平均（ゲイン学習用）とは別に、既存処理で算出済みのフレームRMSを一つだけRAM保持して使用する。学習/ゲイン/音声サンプル処理を変えず、UI読み取り10Hz・300ms失効と送信状態ゲートを適用。RXもactive/draining期間だけ表示し、停止後にSDKが無音コールバックを続けても待受表示へ戻す。
