# TASK: LCD内の設定・電源確認操作

- Issue / 段階: #88 / Console UI追加実装
- 状態: 実装・自動検証済み、画面実操作と実機は未確認。担当Codex、所有者レビュー。2026-11-13。
- 基準: `ccca8e8`、Android 1.0.28 (29) / iOS 1.0 (2026111302)。両OSの既存接続メイン画面。
- 依存: 既存設定APIと保存方式、PTT/Floor不変条件。サーバー変更なし。

## 要求・対象外

SETでLCDを設定メニューへ切り替え、PTT外周の時計回り/反時計回り操作で次/前、PTT中央またはCH「確定」で決定、「取消」で前階層/終了する。POWERもLCDにNO/YESを表示し、既定はNO、同じ操作で選択する。DIAGは従来表示を維持。メニュー中はPTT送信とCH変更を起こさない。既存の設定値、保存、権限・同意、OS設定への誘導を維持する。

## 設計・判断

メイン画面のLCDを固定寸法のメニューページに差し替える。画面モードは通常/設定/電源確認の排他的状態。設定はカテゴリ→項目→選択値の階層とし、位置を明示する。外周のドラッグは角度差を累積し、一定角度ごとに一段だけ進める。中心タップのみ決定に割り当て、外周のジェスチャーと送信ジェスチャーを排他にする。OSがキャンセルした場合は確定しない。電源確認はNOを初期値として明示YESを選び、さらに確定した場合だけ既存leaveを呼ぶ。

設定操作は既存controller/managerのAPIだけを呼ぶ。通信・権限・音声の所有権は変更しない。録音、ログ、本文/音声の保存は追加しない。危険な設定（端末ユーザー変更、背景PTTの同意、入力ゲインのリセット）は専用の確認段を設ける。OS音量の直接変更がプラットフォーム側で許されない場合はハードウェア音量操作をLCDで案内する。

## 受入条件とSTOP

- SET/POWERでLCD内容のみ切り替わり、区画線とLCD高さは変わらない。
- 外周CW/CCWが1段ずつ正しい方向に動き、中心/確定/取消が同じ状態機械を操作する。
- メニュー中のPTTがFloor/TXを開始せず、CHキーがCH変更を起こさない。
- 全既存設定項目を辿れ、値の保存と危険操作の確認が維持される。DIAGは従来のまま。
- 両OSのビルド/既存試験、メニュー状態遷移の回帰試験、可読性・実機未確認事項を記録。実機は新たな有効時間枠がある場合のみ。
- 所有者指定のCodex残量1%で新規試験を停止し、実装/試験/配信/実機の状態を別記録する。追加指示によりTestFlight内部/外部とAndroid GitHub prereleaseへのテスト配信を許可。

## 実装・検証差分

接続中のメイン画面では両OSともSET/POWERで固定LCDを設定/NO-YESに切替。PTT円形の通常ジェスチャーをメニュー中は取り外し、外周の角度差30度で1段、中心タップで決定する別のホイールを表示。CH確定/取消もメニュー入力に切替え、数字CHと2桁は無効化する。設定値は既存の保存/API経路に接続し、端末ユーザー変更・ゲイン履歴消去はYES確認を維持。Android背景PTTの詳細同意だけは既存の長文確認ダイアログを維持し、OSサービス設定はOS画面へ移動する。iOS出力音量はLCD内にOSの音量スライダーを表示する。

利用登録前の画面にはLCD/PTTエリアがないため、その間のSETは従来の設定オーバーレイを維持した。これは要求との差であり、登録前にも同じ外観を適用する場合は別の画面設計が必要。実機・シミュレータのメイン画面操作は未確認。詳細は[検証記録](../testing/RESULTS_20261113_LCD_MENU.md)。
