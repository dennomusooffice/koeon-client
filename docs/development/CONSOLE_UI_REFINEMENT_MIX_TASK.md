# TASK: 固定LCD・CH遷移・透過キーと環境②受入れ

2026-11-11、#88/PR #90、R5。担当Codex、所有者レビュー。基準c445032、公開Android1.0.23(24)/iOS1.0(2026111133)。所有者がAndroid2不具合修正、両OSの半透明キー/内向きLED、環境②での合成音声グループ通話検証を指示。

## 要求・設計

LCDは固定高さと行予算、単行省略、経路/版の単行フッターで内容による拡張を防ぐ。詳細は既存Diagnostics/メンバー一覧で確認。CH切替のleaveでjoined/joinが消えることと画面分岐が原因。表示専用の切替元を保持し、接続中/失敗時もメイン表示を維持、成功で新CHへ置換、明示OFF/登録変更で破棄。表示情報を送信許可やtoken権限に使わない。PTT/Floor/Room再接続の既存安全条件を維持。

両OSは半透明樹脂の面・上面反射・内側へ減衰する埋込LEDを共通意匠にする。CHの緑/青/赤、同桁の左右分割、POWER/Settings/DIAG/PTTの操作領域とpointer所有権を維持。外部画像生成・依存追加なし。

## 検証・受入れ

自動回帰とビルド、長い話者/CH/route/版の固定LCD表示、CH切替成功/復帰/両方失敗/明示OFF、両テーマの画像確認。環境②はSIM5＋許可された実機。実機対象・現在枠は質問中、回答まで実機操作なし。ビルドを先に行い、標準の順で起動。全台READY/人数をゲートとし、3roundの各送信→他全受信制御、合成音のPCM/既知信号検出、ゲインOFF/MANUAL/AUTO/無音、経路を分離評価。失敗時はそのケースを停止し証拠を残す。実声録音なし、合成波形はRAM、数値証拠のみ公開。背景/実Bluetooth/実LTEは許可と接続状況に依存。

STOPは実装・自動/環境②の実測/未検証/復元/正確なbuildをGitHubへ記録。実機期限到達で端末操作停止。公開再配信/mainマージ/本番サーバー変更は本TASKに含めない。試験基盤の不成立を製品成功/失敗と混同しない。
