# Androidの音量ボタンを長押しして送信する

2026-11-11。対象は内部検証版1.0.19-ptt07（20）です。一般配信版への反映済みという案内ではありません。

## 設定

1. KOEONで送信できるユーザー・チャンネルへ接続し、READYを確認します。
2. 「Hardware Volume PTT · 長押し」がTOGGLEであることを確認します。1.0.22（23）以降は未設定時にTOGGLEです。保存済みのOFFは保持します。
3. 背景でも使う場合は「背景で音量PTT（試作）」がONであることを確認します。1.0.22（23）以降は未設定時にON、保存済みのOFFは保持します。OSのユーザー補助サービスは次の手順で手動有効化が必要です。
4. 「背景PTTのOS設定」から、ユーザー補助のダウンロードしたアプリにある「KOEON Background Volume PTT」を有効にします。KOEONへ戻り「OSサービス: 接続済み」を確認します。

Androidが制限付き設定の許可を求める場合は、信頼できる管理者から導入した本アプリであることを確認し、端末の通常の設定画面に従ってください。設定項目の場所は機種によって異なります。

## 操作

音量ボタンの上または下を約0.6秒以上押し続けると、ボタンを離す前に送信開始を要求します。開始音を確認してから話します。もう一度長押しすると停止します。押し続けても開始・停止を繰り返しません。ボタンを離した時にもう一度反転することもありません。

短押しは送信せず、ボタンを離した時に音量を1段階調整します。音量の上下を同時押しする操作はPTTに使いません。

## OPPO A79 5Gで確認した制限

- 画面点灯中のホーム背景で、実ボタンの長押しによる開始・停止を確認しました。
- 点灯したロック画面での開始・停止は前段の短押し版で確認しました。最新長押し版での点灯ロック再試験は未実施です。
- 消灯中の実ボタンは前段試験で送信を開始できませんでした。長押しへの変更は、OSからキーが届かない制約を解消するものではありません。使う場合は先に画面を点灯してください。
- 受信側iPhoneが背景のときは音声不達があり、前面ではPCM受信を確認しました。送信開始音だけで相手への音声到達を保証しません。

無効化する場合は背景PTTをOFF、Hardware Volume PTTをOFFにし、必要に応じてOSの専用サービスもOFFにします。通常の受信機能とは別の設定です。
